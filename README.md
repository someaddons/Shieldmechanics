# Shield mechanics

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_476645_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/476645.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Shield mechanics changes the mechanic of shield blocking to add gear progression to shields allowing better shields to absorb more damage, aswell as adding enchantments on shields.

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
